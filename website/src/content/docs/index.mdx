<CardGrid>
  <Card title="Native first" icon="rocket">
    Dialog, Accordion and Popover are built on `<dialog>`, `<details>` and the Popover API, so focus, `Esc` and screen reader support come from the browser.
  </Card>
  <Card title="Composable" icon="puzzle">
    Components are made of small parts. Combobox, for example, is an input, a list and items that you can arrange yourself.
  </Card>
  <Card title="Themeable" icon="pencil">
    Change a few tokens, or switch between light, dark and system themes. Your own CSS always wins over the library styles.
  </Card>
  <Card title="Accessible by default" icon="approve-check">
    Labels, descriptions, errors, keyboard support and visible focus work out of the box.
  </Card>
</CardGrid>
